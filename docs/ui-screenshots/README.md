本資料夾收錄主網站各畫面在 **390px 手機寬度**下的 Mock Mode 截圖。圖片可直接開啟逐張檢視與微調文案。

- `home-{zh,en}.png`：首頁，中英文。
- `quiz-q1` 至 `quiz-q5`：五題題目頁，中英文。
- `result-{experience|lifestyle|performance}-{precision|rest|pioneer}-{zh|en}.png`：三種跑者 × 三種補水風格，共 18 種結果，中英文。
- `contact-{considering|null}-{zh|en}.png`：聯絡資訊頁；`null` 對應原本自帶補水的流程。
- `redemption-{general|sustainability|paused}-{zh|en}.png`：一般、永續及庫存暫停兌獎頁。

所有操作使用臨時瀏覽器的本機 Mock 資料與虛構測試資料，未連接 Apps Script，也未修改正式庫存。
