# Archive 索引

此目錄只保存已退出主網站的設計稿、原型、截圖及開發歷程，供追溯和參考。主站入口不載入此處的 HTML、CSS、JS 或 CSV。新文件與修改請以 repository 根目錄現行程式及指南為準。

| 位置 | 封存內容 | 狀態／注意事項 |
|---|---|---|
| `cute-prototype/` | Cute Running Club prototype、概念 SVG、舊 V1 CSV、原型測試與截圖 | 不再有 `/cute/` 公開入口；只供歷史視覺參考 |
| `legacy-v1/` | 初代分類／結果程式、V1 文件、舊版截圖及舊內容 CSV | 已退出執行路徑 |
| `design-history/2026-result-page/` | 2026 結果頁參考稿、PDF 與探索圖片 | 設計參考材料，非執行資產 |
| `design-history/assets/` | `永續先鋒隊裝飾.png` | 未被主站引用；正式使用的 `assets/永續先鋒隊.png` 保留在主站 |
| `project-history/v2-review/` | V2 實作驗收報告及對應截圖／JSON | 歷史快照；包含早期聯絡表單或舊圖片畫面，不代表目前流程 |
| `project-history/v2-layout-review/` | 結果頁／兌獎頁早期版面截圖與機器結果 | 歷史視覺迭代 |
| `project-history/V2_CHECKPOINT.md` | 舊版開發檢查點 | 僅供 Git 歷程追溯 |
| `project-history/CODEX_HANDOFF-2026-11-16.md` | 先前工作交接記錄 | 歷史狀態；不作為目前未完成事項清單 |

目前最新的主站手機視覺檢視位於 `docs/ui-screenshots/mobile-launch-review-2026-11-16/`，保留在活躍文件區。封存內容若需重用，先確認它不會覆蓋或誤導現行程式、文案、品牌色及業務規則。
